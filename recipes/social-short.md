# Recipe: Social short

```
HOOK → PATTERN INTERRUPT → VALUE → VISUAL REINFORCEMENT → PAYOFF → CTA
```

**Use for:** Reels, Shorts, TikTok. 9:16, 15–45 s, designed for sound-off.

| Beat | Job | Typical treatment | Length |
|---|---|---|---|
| Hook | Earn the next 2 seconds | KineticText (`size` 170+) | 1.5–2.5 s |
| Pattern interrupt | Surprise — a number, a reversal | MetricCard | 2–3 s |
| Value | The one useful idea | KineticText / CaptionedShort | 4–10 s |
| Visual reinforcement | Show it | Custom: one bold visual built for 9:16; or BarChart / Footage | 3–5 s |
| Payoff | The line people repeat | TitleCard | 2–3 s |
| CTA | Follow / part 2 / link | LogoReveal | 2 s |

**Captions are mandatory** (most viewers watch muted): record VO → `tools/captions`
→ `CaptionedShort` with `captionsFile`. Keep key content out of the bottom
~20% and right edge where platform UI sits (the safe area already helps).
