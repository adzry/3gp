# Recipe: Explainer

```
HOOK → PROBLEM → CONTEXT → EVIDENCE → EXPLANATION → SOLUTION → PAYOFF
```

**Use for:** "how/why does X work", tutorials, concept videos. 60–180 s.

| Beat | Job | Suggested template | Typical length |
|---|---|---|---|
| Hook | Pose the question the viewer already half-has | TitleCard / KineticText | 3–5 s |
| Problem | Make the pain concrete and specific | KineticText | 3–6 s |
| Context | Why now, why it matters | TitleCard (subtitle) | 3–5 s |
| Evidence | One number or exhibit that proves the problem | MetricCard / QuoteCard | 4–6 s |
| Explanation | The mechanism — usually a comparison | BarChart / sequence of TitleCards | 5–15 s |
| Solution | The answer in one line | KineticText | 3–5 s |
| Payoff | What the viewer can now do/see; brand | LogoReveal / TitleCard | 3–5 s |

**Pacing:** ~150 spoken words per minute. A 4 s scene holds ~10 words of VO.
**Pitfall:** explaining before the viewer cares — the hook must be a question, not a claim.
