# Recipe: Product launch

```
PROBLEM → PRODUCT REVEAL → FEATURE → FEATURE → PROOF → RESULT → CTA
```

**Use for:** launches, feature announcements, landing-page videos. 20–60 s.

| Beat | Job | Typical treatment |
|---|---|---|
| Problem | The annoyance, in the customer's words | KineticText |
| Product reveal | Name + one-line promise | LogoReveal |
| Feature ×2–3 | Benefits, not feature names. One per scene | Custom: UI/product demonstration (real screens, animated cursor, zoom to the detail); or TitleCard |
| Proof | A measured number with its method | MetricCard |
| Result | Customer voice | QuoteCard (real customer, with permission) |
| Problem vs product (optional) | Old way vs new way | Comparison (`winner: "right"`) |
| CTA | One action, one URL (+ required credits) | EndCard |

**Variants:** add `"variants": [{ "id": "<id>-vertical", "format": "vertical" }]`
to get a 9:16 cut from the same content for Reels/Shorts/TikTok.
**Pitfall:** more than three features. Cut ruthlessly.
