## Goal
Prove the voice-first pipeline: a recorded narration, transcribed locally with
word timestamps, drives every scene boundary and the word-by-word captions —
over both footage and motion-graphics scenes, in 16:9 and 9:16.

## Audience & channel
3gp itself (README demo). ~45–50 s.

## Key message
Record first; the words set the timing; re-recording re-times everything.

## To finish (requires a human voice)
1. Record `script.md` (VO lines) → `public/projects/002-voice-first-demo/voiceover.wav`
2. `npm run transcribe -- 002` (needs the whisper model — see tools/captions/README.md)
3. `npm run transcript -- 002` — check each scene got the right words
4. `npm run stills -- 002` → review → `npm run render -- 002`
5. Optional: replace the placeholder footage with real clips (log their licences below).

Until then, `npm run stills -- 002 --draft` previews the timing from the script
(DRAFT transcript, muted).
